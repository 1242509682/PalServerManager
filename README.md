# PalServerManager

**PalServerManager** 是一款专为《幻兽帕鲁》(Palworld) 游戏服务器设计的本地管理工具，基于 .NET 8 WinForms 开发。  
它通过 REST API 与 Palworld 服务端通信，提供图形化界面，让您无需手动编辑配置文件或敲命令，即可轻松管理服务器。

---

## ✨ 主要功能

- **🚀 服务端控制**
  - 启动 / 附加 / 停止服务端进程
  - 启动时自动检测并修正 `PalWorldSettings.ini`（确保 REST API 启用且管理员密码有效）
  - **附加进程**：自动查找并附加 `PalServer-Win64-Shipping-Cmd.exe`，无需手动选择进程
  - 支持从配置文件读取启动参数

- **⏱ 自动重启**
  - 基于**运行时间累计**（非固定间隔）自动关服并重启
  - 关服前可自定义等待秒数及广播消息（内置 60 秒预告）
  - **内存监控自动重启**：当系统可用物理内存低于设定阈值时自动关服重启，可自定义检查间隔

- **📢 消息广播**
  - **立即发送**：向当前所有在线玩家广播一条消息
  - **定时发送**：在指定时间发送单次广播
  - **循环发送**：按行分割消息列表，可设置间隔秒数，支持无限循环或有限轮次
  - 消息列表自动保存，下次打开恢复

- **🔨 玩家管理**
  - 获取在线玩家列表（显示 UserID、姓名、IP、延迟、等级、坐标）
  - 一键 **踢出** 或 **封禁** 玩家
  - 封禁时自动记录玩家信息（姓名、IP、等级、封禁时间）
  - 独立的**解封窗口**，以表格形式展示封禁列表，支持选择解封

- **📦 MOD 管理**
  - 自动扫描程序根目录下的 `MyMod` 文件夹，列出所有 Mod（每个子文件夹视为一个 Mod）
  - **安装 Mod**：为 Mod 中的每个文件单独指定目标路径（支持 UE4SS、PalSchema、Pak(~mods)、Pak(LogicMods)、Pak(~WorkshopMods)、服务器根目录等预设路径）
  - **批量设置路径**：勾选多个文件，一键应用预设路径或自定义目录
  - **卸载 Mod**：删除所有已安装文件，并清理空目录
  - **打开目录**：已安装的 Mod 打开安装目录，未安装的打开源文件夹
  - 支持手动编辑目标路径（相对路径/绝对路径），悬停显示完整路径

- **⚙️ 配置编辑**
  - 图形化编辑 `PalWorldSettings.ini` 中的 `OptionSettings` 参数
  - 所有配置项**自动翻译为中文**，便于理解
  - 支持修改字符串、数字、布尔值、枚举及括号表达式（如跨平台设置）
  - 保存后立即生效（需重启服务端）

- **🔧 UE4SS 模组管理**
  - 一键安装 / 卸载 **UE4SS** 及 **PalSchema**
  - 自动从 GitHub 下载最新版本（无需手动下载）
  - 安装后自动配置 `mods.txt`，确保模组正常加载
  - 卸载时**自动强制停止服务端**（如果正在运行），避免文件占用问题，过程简洁快速
  - 提供“打开 Win64 目录”按钮，方便查看安装文件

- **📊 服务器信息与指标**
  - 实时查看服务器版本、名称、世界 GUID 等基本信息
  - 查看当前玩家数、FPS、运行时间、天数等性能指标
  - 信息以中文显示，支持复制

- **🖥️ 友好的界面**
  - 主窗口包含日志区域，自动着色（成功/失败/警告/信息）
  - 状态栏实时显示服务端运行状态、UE4SS 状态
  - 所有功能窗口独立，布局清晰，支持缩放，拉伸时按钮自动适配

## 📦 环境要求

- **操作系统**：Windows 10 / 11（64位）
- **运行时**：.NET 8.0 Desktop Runtime（[下载地址](https://dotnet.microsoft.com/zh-cn/download/dotnet/8.0)）
- **服务端**：Palworld 专用服务器（Windows 版），且**已开启 REST API**（`RESTAPIEnabled=True`）

## 🚀 快速上手

1. **下载并解压**程序到任意目录（建议与服务端同级，方便路径选择）。
2. **双击 `PalServerManager.exe`** 启动。
3. 首次启动会自动生成 `config.json` 配置文件。
4. 在主窗口点击 **“启动服务”**，选择您的 `PalServer.exe`（仅允许选择该文件名）。
   - 若服务端已在运行，可点击 **“附加进程”**，程序将自动查找并附加 `PalServer-Win64-Shipping-Cmd` 进程。
   - 程序会自动检测并修正 `PalWorldSettings.ini`（确保 `RESTAPIEnabled=True` 且 `AdminPassword` 不为空）。
5. 服务端启动后，其他功能按钮（广播、惩罚、控制等）将自动启用。
6. 体验各项管理功能！

## ⚙️ 配置文件说明

程序会在运行目录下生成 `config.json`，包含以下主要配置项（您也可以手动编辑）：

| 配置项 | 说明 |
|--------|------|
| `运行时间累计重启(秒)` | 服务端运行达到该秒数后自动重启（0 禁用） |
| `关服等待时间(秒)` | 执行关服命令后，等待多少秒让玩家保存退出 |
| `关服提示消息` | 关服时广播给玩家的自定义消息 |
| `广播消息列表` | 循环广播的消息内容（多行） |
| `广播无限循环` | 是否无限循环广播 |
| `广播循环间隔(秒)` | 每条消息之间的间隔秒数 |
| `启用内存监控自动重启` | 是否启用基于系统可用内存的自动重启 |
| `内存阈值(MB)` | 当系统可用内存低于该值时触发重启 |
| `内存检查间隔(秒)` | 多久检查一次内存使用情况 |
| `MOD文件安装映射` | 记录每个 Mod 每个文件的目标路径（由程序自动维护） |
| `封禁玩家列表` | 已封禁玩家的详细信息（UserID、姓名、IP、等级、封禁时间） |

> **提示**：所有配置均可在程序界面中修改，`config.json` 仅作为持久化存储。

## 🛠️ 常见问题

### 1. 无法启动服务端，提示“找不到 PalWorldSettings.ini”
- 请确保程序放在服务端根目录，或通过“启动服务”窗口正确选择 `PalServer.exe`。
- 程序会自动从 `Pal\Saved\Config\WindowsServer\` 读取配置。

### 2. 广播或惩罚功能不可用（按钮灰色）
- 请先启动服务端，并等待 REST API 就绪（日志中会显示“REST API 已就绪”）。

### 3. 封禁玩家后，解封窗口不显示玩家信息
- 封禁时程序会保存玩家信息，如果封禁时玩家离线，部分信息可能缺失，但 UserID 必存。

### 4. 程序退出后服务端未停止
- 请使用主窗口的“强制停止”或直接关闭服务端窗口。程序退出时会自动尝试终止服务端进程。

### 5. MOD 安装失败，提示“需要安装 UE4SS”
- 请先通过“UE4SS”按钮安装 UE4SS + PalSchema，然后再安装此类 Mod。

### 6. MOD 卸载后文件仍残留
- 若文件被占用，程序会尝试删除，部分残留可手动清理。卸载时会提示删除失败的文件路径。

### 7. 如何更新服务端？
- 本程序**不包含** SteamCMD 更新功能，需要您自行通过 SteamCMD 或游戏平台更新服务端文件。
